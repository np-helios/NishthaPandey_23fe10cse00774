# NLTK Real Python Tutorial Project

This project reproduces the main commands and examples from the Real Python tutorial:
[Natural Language Processing With Python's NLTK Package](https://realpython.com/nltk-nlp-python/).

## Files

- `realpython_nltk_tutorial.py` runs the tutorial examples in sequence.
- `requirements.txt` lists the Python packages needed.

## How to Run

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 realpython_nltk_tutorial.py
```

## What the Script Covers

- Tokenizing
- Filtering stop words
- Stemming
- Part-of-speech tagging
- Lemmatizing
- Chunking
- Chinking
- Named entity recognition
- Loading NLTK book corpora
- Concordance analysis
- Dispersion plots
- Frequency distribution
- Collocations
