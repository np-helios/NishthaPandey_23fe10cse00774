# Basic GenAI Commands

This file contains very basic Generative AI commands/prompts that can be used to understand how GenAI works.

## 1. Text Generation

Prompt:

```text
Write 5 lines about artificial intelligence in simple words.
```

Use:
- Generates new text from a prompt

## 2. Summarization

Prompt:

```text
Summarize the following paragraph in 3 lines.
```

Use:
- Creates a short summary from long text

## 3. Translation

Prompt:

```text
Translate the following sentence from English to Hindi: "Machine learning is very useful."
```

Use:
- Converts text from one language to another

## 4. Question Answering

Prompt:

```text
What is Natural Language Processing?
```

Use:
- Gives direct answers to simple questions

## 5. Rewriting

Prompt:

```text
Rewrite this sentence in a formal tone: "I can't come today."
```

Use:
- Changes the tone or style of writing

## 6. Grammar Correction

Prompt:

```text
Correct the grammar: "She go to school every day."
```

Use:
- Fixes grammar mistakes in text

## 7. Brainstorming Ideas

Prompt:

```text
Give me 10 project ideas related to AI for beginners.
```

Use:
- Helps generate new ideas

## 8. Code Explanation

Prompt:

```text
Explain this Python code in simple words.
```

Use:
- Explains programming code step by step

## 9. Email Writing

Prompt:

```text
Write a polite email to my teacher asking for an extension on the assignment.
```

Use:
- Drafts emails and formal messages

## 10. Chatbot Style Prompt

Prompt:

```text
Act like a friendly tutor and explain machine learning to a beginner.
```

Use:
- Changes the role or behavior of the AI

## Conclusion

These are simple GenAI prompt examples that show how Generative AI can be used for:

- writing
- summarizing
- translating
- answering questions
- correcting grammar
- generating ideas
- explaining code

This file is useful for beginners who want to learn the most basic GenAI commands.
